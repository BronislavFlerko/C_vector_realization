## C vector realization
### Проект выполнил Бронислав Флерко

### Описание:
Проект представляет из себя простую реализацию вектора на языке Си для int. Работа создана, что бы улучшить понимание работы динамических структур данных и управления памятью в Си.

### Основные возможности:
* Динамическое расширение - автоматическое увеличение capacity при добавлении элементов.

* Базовые операции - добавление/удаление элементов, доступ к элементам.

* Управление памятью - ручное управление через malloc/realloc/free.

* Изменение размера - функции Resize и Reserve для контроля памяти.

### Небольшие примеры использования:

1. "Конструктор" по умолчанию:

```
#include "c_vector.h"
#include <stdio.h>

int main() {
    struct c_vector_int v;
    ctor_vector_default(&v);
    
    PushBack(&v, 10);
    PushBack(&v, 20);
    PushBack(&v, 30);
    
    printf("Размер: %d\n", GetSize(&v));      // 3
    printf("Последний: %d\n", GetBack(&v));   // 30
    
    dtor_vector_int(&v);
    return 0;
}
```

2. Добавление и удаление:

```
#include "c_vector.h"

int main() {
    struct c_vector_int nums;
    ctor_vector_default(&nums);
    
    // Добавляем числа 1-5
    for (int i = 1; i <= 5; i++) {
        PushBack(&nums, i);
    }
    
    // Удаляем все с конца
    while (!IsEmpty(&nums)) {
        PopBack(&nums);
    }
    
    dtor_vector_int(&nums);
    return 0;
}
```

3. Создание с параметрами:

```
#include "c_vector.h"

int main() {
    struct c_vector_int vec;
    
    // Вектор из 5 элементов, все = 100
    ctor_vector_with_param(&vec, 5, 100);
    
    // Теперь в vec.data лежит [100, 100, 100, 100, 100]
    
    dtor_vector_int(&vec);
    return 0;
}
```




### Планы по развитию:
На данный момент реализация предоставляет работоспособный, но не до конца отточенный код. В пример шероховатостей - отсутствие проверок выхода за границы, местами выбивающая стилизация/оформление и другие мелкие спорные моменты реализации. На данный момент считаю важным просто обозначить осведомлённость и факт наличия проблем, в нынешней форме проект не претендует на звание production-ready решения.

Однако эта реализация - не конечная точка. Текущая версия для int сознательно сделана максимально простой и "прямолинейной", чтобы:

* Отладить базовую механику - управление памятью, инварианты структуры.

* Создать прототип для более сложной задачи.

### Главная цель: generic-вектор на Си.
Эта int версия - первый шаг к созданию полноценного контейнера.
